# Monthly changelog

## Idea
Each release generates a changelog from the PR titles on `main` after v1.0.0, grouped by calendar month, with git-cliff and the rules in `cliff.toml`. Nothing is committed. The app shows the recent months in Settings > About, and the update window shows what the offered release adds. The full changelog is on a GitHub Pages page and is a file of each release.

## Why
Version numbers change with each merged PR, so they tell users little. The GitHub Releases page lists changes by version, not by time.
