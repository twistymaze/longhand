# Remember a speaker count per folder

## Idea
A recurring table is always the same size, so a destination folder could carry its own default speaker count or range.

## Why
The diarization engine does better with an exact or bounded count. A count is not an identity, so this stays inside the no-speaker-identity boundary.

## Current state
Partly built: a session can carry an optional count or range (KD15, R36), with a single app-wide default in Settings and a per-session override. What remains is a default per folder.
