# A recording shortcut per destination folder

## Idea
Bind a hotkey per destination: one for Pathfinder, one for work. Recording stays decision-free while the destination becomes implicit.

## Why parked
Considered and set aside in favour of a default folder you move sessions out of later. Worth revisiting if moving becomes tedious.
