# Choose the summary model from the server's list

## Idea
In Settings, Model becomes a searchable picker that Longhand fills from the endpoint's list of models. A status line shows whether the Base URL and API key work. Base URL starts as OpenAI's endpoint.

## Why
The user must type an exact model id today, and a wrong URL, key or model shows only when a summary fails.
