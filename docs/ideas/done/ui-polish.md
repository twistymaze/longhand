# Library and desktop UI polish

## Idea

Use click-to-select and double-click-to-open in the library, keep a note selected whenever notes exist, and remove alert-audibility warnings. Add keyboard zoom and Start at login. Use a shared SVG mark and a larger home brand heading.

## Why

Hover previews proved difficult to use. The user wants familiar desktop controls and consistent branding across themes and app icons.
