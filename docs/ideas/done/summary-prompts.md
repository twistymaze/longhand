# Saved summary prompts

## Idea
Settings holds a list of named summary prompts, with one active. Two built-in prompts: "Topic summary" (the default) and "Play-by-play summary" (today's time-ordered shape). The user edits what the summary contains and how it is organized. The app keeps the fixed rules that make summaries correct.

## Why
The single built-in summary shape does not fit game sessions or 1:1 meetings, and different meeting types need different shapes.
