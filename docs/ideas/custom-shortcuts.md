# Choose the shortcuts

## Idea
The user sets the recording shortcut by pressing the keys, as in Handy, and can reset or clear it. A second, optional "Show Longhand" shortcut shows the main window from the menu bar, and a second press hides it.

## Why
The recording shortcut is fixed at `CommandOrControl+Alt+Shift+L`. When the main window is closed, only the menu-bar item or the recording shortcut brings it back.
