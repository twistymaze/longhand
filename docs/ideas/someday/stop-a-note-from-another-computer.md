# Stop a note from another computer

## Idea
When a note records on one computer, another computer that shows it as "In use on another computer" can ask the recording computer to stop it, through the storage folder.

## Why
The user saw a forgotten 43-hour recording from a laptop, but had to connect to the work Mac remotely to stop it.

## Notes / Current state
The forgotten-recording plan stops an unattended note on the recording computer itself. This idea covers the case where the user sees the note first on another computer.
