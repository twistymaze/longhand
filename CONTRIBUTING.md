# Contributing to Longhand

Thank you for your interest in Longhand.

Longhand is a young project, and its design still changes often. For now, I am not taking outside contributions: only collaborators can open pull requests and issues. I hope to change that when the project is more settled.

You are welcome to follow along. Watch the repository to see new work, read the plans in [`docs/plans/`](docs/plans/), or build Longhand yourself with the steps in the [README](README.md).
