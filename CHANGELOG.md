# Changelog

The changelog of Longhand is at https://twistymaze.github.io/longhand/changelog/. It lists the changes by month.

Each release also has the changelog as of that release: the `CHANGELOG.md` file in its assets on the [Releases page](https://github.com/twistymaze/longhand/releases). [Releases](docs/releases.md#changelog) tells how the changelog is made.
