# Security policy

## Report a vulnerability

Do not report a vulnerability in a public issue. Use [private vulnerability reporting](https://github.com/twistymaze/longhand/security/advisories/new). Only the maintainer can read the report.

Give the Longhand version, the operating system, and the steps that show the problem.

## Supported versions

Only the latest release gets security fixes. Longhand updates itself, so a fix reaches users in a new release.
